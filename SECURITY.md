# Security status

The frontend currently uses illustrative preview data and performs no wallet or financial operation. The Solidity and indexing code under `prototypes/` is experimental, unaudited, and unsuitable for real funds until its release gates are met.

Do not post private keys, seed phrases, personal account documents or wallet-session secrets in issues. For an exploitable finding, use GitHub's private vulnerability reporting if enabled rather than publishing reproduction details in a public issue. If private reporting is unavailable, open an issue asking for a private contact without including the exploit.

Passing local tests does not establish security of every external dependency, deployment, asset or economic configuration.
